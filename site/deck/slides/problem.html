The problem

Bitcoin lives on many layers. A payment code names just one.

Different layers

Bark, Arkade, Lightning, on-chain. Payer and receiver often hold different ones.

No way to say what you accept

An invoice or an address names one layer. There is no "this first, then that".

Swaps are siloed

Each wallet wires in one swap service. If it stops, the feature stops.

Three gaps. First, bitcoin is spread across Ark (Bark and Arkade), Lightning and on-chain, and two people often hold different ones. Second, payment codes name one layer: an invoice is Lightning, an address is on-chain. A receiver has no place to say "I prefer Bark, then Lightning, then on-chain". Third, swaps are wired one to one: a wallet integrates a single swap service, so when that service stops, the wallet loses the feature. Example if useful: when Boltz paused swaps in August, the wallets built on it lost swaps overnight.
