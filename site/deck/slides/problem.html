The problem

Bitcoin lives on many layers. Payments don't.

RECEIVER

One code, one layer

An invoice is Lightning, an address is on-chain. A merchant can't say "stablecoins first, then Lightning".

PAYER

Holds a different layer

The receiver wants Arkade, I hold Bark. Two Ark wallets on different servers can't pay each other.

SWAPS

Siloed

Each wallet wires one swap service. No way to compare providers or pay any address out there.

Receivers can only express one layer per code. Payers often hold a different layer than the receiver wants, for example Bark versus Arkade. And swaps are wired one service per wallet, so users cannot compare providers or reach every address type.
